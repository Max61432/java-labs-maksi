# Лабораторная работа 2: Классы и инкапсуляция

Условие: [`assignments/lab02-domain-model.md`](../assignments/lab02-domain-model.md).

Из корня репозитория запустите:

```bash
./mvnw -pl lab02 test
```

Windows PowerShell: `.\\mvnw.cmd -pl lab02 test`.

Основной код размещайте в `src/main/java/edu/course/lab02/`, тесты — в `src/test/java/edu/course/lab02/`. В начале каждого Java-файла укажите `package edu.course.lab02;`.

Модуль независим от остальных лабораторных. Если нужны модели из предыдущей работы, перенесите и при необходимости адаптируйте только нужные классы в этот модуль. Начальная успешная сборка не является выполнением задания: создайте реализацию и собственные тесты по условию.

## Инварианты модели

### BankAccount
- Баланс никогда не отрицательный.
- Пополнение возможно только положительной суммой.
- Списание возможно только положительной суммой и не превышающей текущий баланс.
- Поле `balance` закрыто, сеттер отсутствует.

### DataSample
- `id` не равен `null` и не пуст.
- `label` не равен `null` и не пуст.
- `status` не равен `null`.
- `features` не равен `null`, не пуст и содержит только конечные числа (без `NaN` и `Infinity`).
- Массив `features` копируется в конструкторе и при возврате из accessor — внешний код не может изменить состояние объекта через ссылку на массив.
- Статус меняется только через `changeStatus`, сеттеров для полей нет.
- Модель не читает из консоли и ничего не печатает.
