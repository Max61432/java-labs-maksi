## Обоснование выбора коллекций
- `ArrayList` для стека `Stack<T>`: нужен быстрый доступ по индексу и операции добавления/удаления с конца (амортизированная сложность O(1)).
- `HashMap` для подсчета статусов (`countByStatus`): обеспечивает быстрый доступ по ключу (O(1)) и не требует порядка элементов.
- `HashSet` для уникальных источников (`getUniqueSources`): гарантирует уникальность элементов за O(1) и не требует порядка.
- `ArrayList` для отсортированного списка: позволяет создать копию исходного списка и отсортировать её без изменения оригинала.
